# fallback-media/images

اینجا برای وقتیه که همه‌ی provider های استوکِ عکس (Pexels و هرچی بعدش تو
صفحه‌ی «ارائه‌دهنده‌های API» تنظیم کردی) شکست بخورن — به‌جای این‌که کل
رندر متوقف بشه، کد از یکی از عکس‌های همین پوشه استفاده می‌کنه.

**چند فایلِ jpg/png اینجا بذار** — چیزی عمومی و بی‌ربط‌به‌موضوعِ خاص که تو
هر ویدیویی جواب بده (مثلاً چند تا چشم‌انداز طبیعت، آسمان، دریا، جنگل).
اسمِ فایل مهم نیست، فقط پسوندش درست باشه. اگه این پوشه خالی بمونه، هیچ
اتفاقی نمی‌افته — کد فقط از fallback محلی صرف‌نظر می‌کنه و همون خطای
اصلی رو نشون می‌ده (رفتارِ قبل از این تغییر).
